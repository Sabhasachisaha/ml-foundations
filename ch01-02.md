# StatQuest ML Book, Ch 1-2: 5 Key Ideas

1. **Machine learning** turns data into decisions in two ways: **classification** (put things into groups) and **regression** (predict a number).
2. **Features** (independent variables) are the inputs we use to predict the **target** (dependent variable). Example: weight → height.
3. **Training data** is what the model learns from; **testing data** is new data used to check it. Testing on the training data is **data leakage**.
4. **Overfitting** = great on training data, poor on new data. We pick the model that does best on testing data, not training data.
5. **Cross-validation** takes turns using each group of the data for testing. 10-fold for large data; leave-one-out for very small data.
